# Screenshot provenance

Content in every image is synthetic or demo content.
Conversation content is synthetic and was not sent to a model or live user
conversation. These images illustrate the product; distribution, real-network
and notification acceptance are separate checks.

| Asset | Source |
| --- | --- |
| `chats.png`, `approval.png` | Copies of the App Store screenshots `iPhone 6.1-01-chats.png` and `iPhone 6.1-04-approvals.png` (`fastlane/screenshots/en-US/`, recaptured from the current app on October 19, 2026 with demo content, commit a79b97cc). The README shows them. |

`pairing.png` and `mac-permissions.png` were captured September 20. They show the
native Add computer sheet before a link is entered and the installed Mac Access
settings above the private folder list. The simulator pairing image uses the
paste-link fallback. Granted permissions reflect the capture Mac, not a fresh install.

The capture fixture and test are confined to Diagnostics. Release excludes them.
The image bytes are unaltered. Captures, test results, source mapping and privacy
review evidence are retained locally; they are not public release artifacts.
